# v0.7.9

本次版本聚焦「设置体验收敛」与「后端结构治理」，不新增播放核心功能，但让设置界面更简洁、代码结构更清晰。

## ✨ 变更 (Changes)

- **设置界面统一为标签页模式**：移除「滚动 / 多栏 / 选项卡」布局切换选项，设置页现始终使用标签页（选项卡）布局，新 UI 开启时仍沿用 WinUI3 侧边导航。

## 🎨 改进 (Improvements)

- **设计器并入设置页**：原独立「设计器」页面的外观令牌（界面圆角、毛玻璃模糊、浮层阴影、主题色辉光、字体晕影、动画速度）与背景 / 透明设置，全部并入「设置 → 外观」区，去除了独立预览面板。外观调整现在可在设置页内完成，无需切换页面。
- 清理 `libraries` 页设计器入口按钮、引导教程与页面导航中的设计器引用。

## 🗑 移除 (Removed)

- **虚空模式（Void Mode）**：彻底移除相关界面开关、颠倒 / 手电筒逻辑、注入样式与本地存储同步。
- 移除独立设计器页面（`designer.html / designer.js / designer.css`）。

## 🧩 技术 / 后端 (Engineering)

- **后端模块化重构**：将内聚、低耦合的模块从单一 `app` 包拆分为独立子包，`MusicService` 作为门面委托：
  - `app/equalizer`：10 段图形均衡器（biquad peaking filter，纯实现）
  - `app/share`：ID3v2.4 标签构造 / 剥离 / 文件名清理（纯函数）
  - `app/stats`：听歌时长跟踪器（`Tracker`，跨平台 JSON 持久化）
- `app/settings`：移除废弃的 `SettingsLayout` 与 `VoidMode` 字段。

## 🧪 兼容性

- 旧版 `settings.json` 中的 `settings_layout` / `void_mode` 字段将被安全忽略（无破坏性迁移）。
- 前端 4 个改动文件均通过 ESM 语法校验；后端 `go build ./app/... ./internal/...` 与 `go vet` 全部通过。
